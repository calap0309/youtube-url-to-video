How does 720p download work?

With your domain (VPS): yourdomain.com runs Node + yt-dlp + ffmpeg. The browser calls /api/info and /api/download?quality=720 on the same domain — single domain, no CORS.

Fallback (GitHub Pages): if the backend is unreachable, the app calls the open-source Cobalt API (api.cobalt.tools) directly from your browser. For personal use only — respect YouTube's Terms and copyright.
